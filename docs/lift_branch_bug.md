# Bug 复盘：抓取后手臂大幅扫弧问题

## 1. 症状

脚本专家（无模型控制）执行 pick-and-place 时，抓取和放置本身都成功
（成功率 20/20），但**持物运输段（lift → above_pad）轨迹异常**：

- 抓起方块后，末端不是垂直上升，而是俯冲到离桌面仅 3cm 的高度；
- 贴着桌子平扫一大段弧线再爬升到垫子上方；
- 实测路径长度 0.578m，为直线距离（0.238m）的 **2.4 倍**。

## 2. 排查过程

### 2.1 定位异常发生的阶段

逐阶段记录 IK 解的腰 yaw 关节角：

| 阶段 | 腰 yaw (rad) | 说明 |
|---|---|---|
| home / above_obj | ≈ 0 | 正常 |
| descend | +0.75 | 下降需要扭腰（见 2.2） |
| **lift** | **+1.96** | **异常：跳到第三个分支** |
| above_pad | -0.08 | 又要转回来 → 大弧扫摆 |

相邻阶段间构型差最大的就是 lift（+1.96 → -0.08），关节空间插值在这
两个构型之间直线运动，末端便扫出大弧并下潜。

### 2.2 排除"选错解"——锁腰实验

对"下降必须扭腰"做控制变量实验（腰 yaw 限位钳制在当前值 ±0.05）：

- **锁腰后下降目标无解**（末端误差 40~94mm，不是容差问题）；
- 且以下组合**全部**无解：安装角 0°/30°/60°/90°、桌面高度 0.72/0.75/0.77、
  姿态容差放松到 0.35rad、工作区平移到机器人正前方。

**结论：竖直接近 + 抓取高度（桌面 0.72，肩高 1.08，落差 33cm）必须扭腰，
是本构型下的几何性质，不是求解器或参数问题。**

### 2.3 排除"连续跟踪"——小步链实验

将 lift 从一步 14cm 改为 2cm 小步、每步 IK 只用前一步解作种子
（连续跟踪解流形）。从纯 IK 解出发时腰平滑变化（0.71 → -0.16），
但从**仿真实测构型**出发时腰仍单调爬升到 +1.96：

```
lift 起点（实测腰 +0.96）逐 2cm 上升: 腰 0.96 → 1.43 → 1.56 → 1.77 → 1.96
```

说明解流形在此区域呈**螺旋结构**：从抓取构型出发的连续上升路径必然
多拧一圈腰，不存在通往悬停构型（腰 ≈ 0）的短连续路径。

## 3. 根因

```
8 个关节自由度 > 6 维任务约束
  → 每个末端目标对应无穷多组关节解（冗余）
  → 3D 目标 + 姿态约束无法表达"要哪个分支"这条信息
  → lift 独立求解时 IK 返回远处分支（腰 +1.96，同样是有效解）
  → 关节插值在两个远分支间直线过渡 → 末端扫大弧
```

补充尝试过且无效的方案：零空间偏置拉向当前构型（增益 0.05~1.0）、
多候选挑最近、lift 改用笛卡尔伺服（腰漂至 +1.55 且不收敛）。

## 4. 解决方案：lift 原路返回

**lift 不再独立解 IK，直接复用 above_obj 阶段保存的悬停关节构型**
（下降是怎么下去的，就原路升回来）：

```python
# expert.py _enter_phase()
if ph == "above_obj":
    self._q_hover = q_star          # 保存已知好构型
if ph == "lift":
    self._q_star = self._q_hover    # 原路返回，不解 IK
```

原理：与其用 6 维目标让 IK 重新"抽签"选分支，不如直接指定 8 维的
完整答案——above_obj 的构型已被验证可达且离垫子上方目标很近。
这是机械臂操作里的标准手法（沿接近路径原路撤回）。

descend/place 保留 2cm 小步链（这两个方向的流形跟踪是良性的）。

## 5. 结果

| 指标 | 修复前 | 修复后 |
|---|---|---|
| 运输段路径弯曲系数 | 2.4x | **1.03x（近似直线）** |
| 路径最低点高度 | 0.749m（离桌 3cm） | 0.838m |
| 腰 yaw 依次为 | 0 → 0.75 → 1.96 → -0.08 | 0 → 0.83 → 0.01 → -0.04 |
| 专家成功率 | 20/20 | **20/20** |
| 回放/冒烟测试 | — | 全部通过 |

## 6. 经验总结

1. **末端目标不携带分支信息**：冗余机器人上，"目标正确"与"解正确"
   是两回事；需要连续性时，必须显式提供参考构型或复用已知解；
2. **先画地图再动手**：逐阶段记录关节解、锁关节做控制变量、
   小步链测流形——每一步实验都排掉一类假设，避免盲改参数；
3. **几何性质躲不开只能顺着走**：扭腰不可避免时，让它在下降时
   平滑发生、上升时原路收回，比强行找"不扭腰的解"简单且可靠。
